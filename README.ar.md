# perso-match — البحث مع الحفاظ على النص الأصلي

قد يفشل البحث عن «محمد» في العثور على «مُحَمَّد»، أو تختلف النتائج بين الأرقام `123` و`١٢٣` و`۱۲۳`. تعالج هذه المكتبة اختلافات محددة في الكتابة وتعيد مواضع النتائج داخل النص الأصلي لعرضها بشكل صحيح.

```sh
npm install perso-match
```

```ts
import { createMatcher } from 'perso-match';
const matcher = createMatcher({ locale: 'ar' });
const parts = matcher.parts('مرحباً يا مُحَمَّد', 'محمد');
// الجزء المطابق يحتوي على «مُحَمَّد» كما وردت في النص الأصلي.
```

تُوحَّد أشكال الياء والكاف الفارسية والعربية، وتتحول الأرقام إلى الأرقام اللاتينية كنص، مع الحفاظ على الأصفار في البداية. تُتجاهل الحركات الشائعة والتطويل في مفتاح البحث. لا تُوحَّد التاء المربوطة مع الهاء، ولا تُحذف الهمزة افتراضياً.

يمكن تفعيل `alef: 'fold'` لتوحيد أ وإ وآ وٱ مع ا، و`foldMaqsura: true` لتوحيد ى مع ي. هذه الخيارات قد تزيد النتائج غير المقصودة؛ اخترها بحسب بيانات التطبيق.

احتفظ بالنص الأصلي في قاعدة البيانات وخزّن مفتاح البحث في عمود منفصل مع `matcher.profile`. استخدم `matcher.collisions(rows, row => row.name)` لمراجعة النصوص المختلفة التي تنتج المفتاح نفسه قبل ترحيل البيانات. لا تستخدم المفتاح كدليل على تطابق هوية شخصين أو كقيد فريد.

المكتبة لا تنشئ HTML. اعرض الأجزاء باستخدام `textContent` أو آلية الهروب الافتراضية في إطار الواجهة. المواضع هي إزاحات UTF-16 مناسبة للدالة `String.slice` في JavaScript.
